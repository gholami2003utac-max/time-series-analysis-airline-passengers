Part 4– Augmented Dickey–Fuller (ADF) test

Part (a)

The trend specification is appropriate because the run-sequence plot shows a clear upward trend in the airpass series. Therefore, both an intercept and a linear time trend should be included in the ADF regression.

The chosen equation is:

\(Δyₜ = α + βt + γyₜ₋₁ + εₜ\)

The null hypothesis \(H₀: γ = 0\) means that the series has a unit root and is non-stationary. The alternative hypothesis \(Hₐ: γ < 0\) means that the unit-root hypothesis is rejected and the series is stationary around a deterministic linear trend.

# Function to estimate the trend ADF regression
run_adf_manual <- function(p) {
    
    # Create data frame with fixed sample
    dat <- data.frame(
        dy = response,
        trend = trend,
        lag_y = lag_y
    )
    
    # Add lagged differences
    if (p > 0) {
        for (j in 1:p) {
            dat[[paste0("dy_lag", j)]] <-
                dy[(13 - j):(n - 1 - j)]
        }
    }
    
    # Construct regression formula
    predictors <- c("trend", "lag_y")
    
    if (p > 0) {
        predictors <- c(
            predictors,
            paste0("dy_lag", 1:p)
        )
    }
    
    formula_adf <- as.formula(
        paste("dy ~", paste(predictors, collapse = " + "))
    )
    
    # OLS estimation
    model <- lm(formula_adf, data = dat)
    
    # Extract coefficient of lagged level
    coef_table <- summary(model)$coefficients
    
    gamma_hat <- coef_table["lag_y", "Estimate"]
    se_gamma <- coef_table["lag_y", "Std. Error"]
    
    # ADF t-statistic
    t_adf <- gamma_hat / se_gamma
    
    # Information criteria
    aic_value <- AIC(model)
    bic_value <- BIC(model)
    
    return(data.frame(
        Lag = p,
        Gamma = gamma_hat,
        SE_Gamma = se_gamma,
        ADF = t_adf,
        AIC = aic_value,
        BIC = bic_value
    ))
}

# Run for p = 0,...,12
results_adf <- do.call(
    rbind,
    lapply(0:12, run_adf_manual)
)

Part 5– Phillips–Perron (PP) test

Part (a)

The ADF and PP tests have the same basic hypotheses: the null hypothesis states that the series has a unit root, while the alternative hypothesis states that the series is stationary under the chosen deterministic specification.

The ADF test handles serial correlation by adding lagged differences to the regression. The selected ADF model uses p lagged-difference terms. In contrast, the PP test uses a non-parametric correction based on the long-run variance to account for serial correlation and heteroscedasticity without adding lagged-difference regressors. Therefore, ADF uses additional degrees of freedom as more lags are included, whereas PP does not lose regression degrees of freedom through additional lagged-difference coefficients.

(a) Comparison of ADF and PP Tests

Both the Augmented Dickey–Fuller (ADF) and Phillips–Perron (PP) tests examine the null hypothesis that a time series contains a unit root and is therefore non-stationary.

The main difference is how they handle serial correlation. The ADF test adds lagged differences to the regression, which requires estimating additional parameters and reduces the degrees of freedom. In contrast, the PP test uses a non-parametric correction to account for serial correlation and heteroscedasticity without adding lagged differences to the regression.

(b) Residual Analysis

The selected ADF model used 12 lagged differences and produced 131 residuals. The residual plots showed some large fluctuations and spikes, particularly toward the end of the sample, suggesting possible changes in volatility.

The Ljung–Box test on squared residuals produced the following results:

  • X-squared = 5.5287

  • Degrees of freedom = 12

  • p-value = 0.938

Since the p-value is greater than 0.05, the null hypothesis of no autocorrelation in squared residuals up to lag 12 cannot be rejected. Therefore, there is no significant evidence of autocorrelation in squared residuals. However, this does not necessarily prove constant variance.

The PP test is useful as a complementary test because it accounts for serial correlation and heteroscedasticity through a non-parametric correction.

(c) Phillips–Perron Test Results

The PP test was performed using a model with an intercept and a linear trend.

The hypotheses are:

  • H0: The series has a unit root and is non-stationary.

  • H1: The series is stationary around a deterministic linear trend.

Part 6– KPSS test

(a) State H0 and Ha of KPSS.Suppose ADFrejects its null for some series: which KPSS outcome

would confirm stationarity and which would contradict it? Explain why the opposite null hypotheses make KPSS useful as a confirmatory test.

The KPSS (Kwiatkowski–Phillips–Schmidt–Shin) test is used to examine whether a time series is stationary. Unlike the ADF and PP tests, the KPSS test has stationarity as its null hypothesis.

There are two main versions of the KPSS test:

  1. Trend Stationarity

\(H_0\)​ : The time series is stationary around a deterministic linear trend.

\(H_a\) ​ : The time series is non-stationary and contains a unit root.

  1. Level Stationarity

\(H_0\) ​ : The time series is stationary around a constant mean (level).

\(H_a\) ​ : The time series is non-stationary.

Relationship between ADF and KPSS tests:

The ADF and KPSS tests have opposite null hypotheses. The ADF test assumes that the series contains a unit root under the null hypothesis, whereas the KPSS test assumes that the series is stationary.

If the ADF test rejects its null hypothesis, evidence supports stationarity. A KPSS result that fails to reject its null hypothesis would confirm this conclusion.

However, if both tests reject their respective null hypotheses, their results contradict each other. This may indicate that the series has more complicated characteristics, such as structural breaks, changing variance, or an inappropriate deterministic specification.

Therefore, using both tests provides a more comprehensive assessment of stationary.

(c) Final Verdict on the Raw AirPassengers Series

Based on the graphical analysis, summary statistics, and statistical tests, the raw AirPassengers series is not stationary in its original form.

The following sources of non-stationary have been identified:

  1. Trend: The series has a clear upward trend from 1949 to 1960, indicating that its mean is not constant over time.

run_tests <- function(x, specification) {
    
    adf_type <- if (specification == "trend") "trend" else "drift"
    pp_model <- if (specification == "trend") "trend" else "constant"
    kpss_type <- if (specification == "trend") "tau" else "mu"
    
    adf_aic <- ur.df(
        x, type = adf_type,
        lags = 12, selectlags = "AIC"
    )
    
    adf_bic <- ur.df(
        x, type = adf_type,
        lags = 12, selectlags = "BIC"
    )
    
    adf_aic_stat <- as.numeric(adf_aic@teststat[1, 1])
    adf_bic_stat <- as.numeric(adf_bic@teststat[1, 1])
    
    adf_aic_cv <- as.numeric(adf_aic@cval[1, "5pct"])
    adf_bic_cv <- as.numeric(adf_bic@cval[1, "5pct"])
    
    pp <- ur.pp(
        x, type = "Z-tau",
        model = pp_model, lags = "short"
    )
    
    pp_stat <- as.numeric(pp@teststat)
    pp_cv <- as.numeric(pp@cval[1, "5pct"])
    
    kpss <- ur.kpss(
        x, type = kpss_type, lags = "short"
    )
    
    kpss_stat <- as.numeric(kpss@teststat)
    kpss_cv <- as.numeric(kpss@cval[1, "5pct"])
    
    list(
        ADF_AIC = adf_aic_stat,
        ADF_BIC = adf_bic_stat,
        PP = pp_stat,
        KPSS = kpss_stat,
        
        ADF_AIC_Decision = if (adf_aic_stat < adf_aic_cv)
            "Reject H0" else "Do not reject H0",
        
        ADF_BIC_Decision = if (adf_bic_stat < adf_bic_cv)
            "Reject H0" else "Do not reject H0",
        
        PP_Decision = if (pp_stat < pp_cv)
            "Reject H0" else "Do not reject H0",
        
        KPSS_Decision = if (kpss_stat > kpss_cv)
            "Reject H0" else "Do not reject H0"
    )
}

    )

Part (e) – Interpretation

(i) Choice between Route A and Route B

The joint-testing results support both transformation routes. For Route A, the ADF and PP tests reject the unit-root null, while the KPSS test does not reject the stationarity null. This supports stationarity after removing the deterministic quadratic trend and monthly seasonal effects.

For Route B, the ADF tests using both AIC and BIC, the PP test, and the KPSS test also support stationarity after regular and seasonal differencing.

However, the test results for the original series do not conclusively distinguish between deterministic and stochastic trends. The PP and KPSS trend tests are compatible with trend stationarity, although the ADF test does not reject the unit-root null.

I would slightly favour Route A for modelling. The quadratic trend is statistically significant, and both AIC and BIC favour the quadratic model over the linear model. Furthermore, Route A has a lower chunk variance ratio (1.297) than Route B (2.809), indicating more stable variance across the three chunks. Therefore, I would use the Route A final residual series for modelling, while recognising Route B as a valid alternative under the stochastic-trend assumption.

(ii) Variance comparison

The log transformation substantially stabilises the variance. The ratio of the largest to the smallest chunk variance decreases from 5.629 in the original series to 1.284 in the log-transformed series. This provides strong justification for applying the logarithmic transformation.

The effect of first differencing and seasonal differencing on the overall variance should be assessed using the calculated sample variances of the three transformed series. These transformations are primarily intended to remove stochastic trend and seasonal dependence, rather than to minimise variance.

First differencing is justified by the trend and the stationarity diagnostics. Seasonal differencing is justified by the remaining annual seasonal pattern in the first-differenced series and its ACF. Therefore, even if either differencing operation increases the overall variance, it can still be appropriate if it removes a source of non-stationarity.
